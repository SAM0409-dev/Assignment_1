## Overview

This assignment focuses on using **Pandas and NumPy** to work with a deliberately messy IT services support ticket dataset.

The dataset contains approximately **51,500 support tickets** from a fictional IT services firm. The data includes inconsistent column names, missing values, different date formats, numeric values stored as text, inconsistent categorical values, and other data-quality issues.

## Dataset

**File:** `it_services_tickets_raw.csv`

The dataset contains information about:

* Tickets and ticket status
* Client information
* Service lines
* Priority
* Assigned engineers
* Billing rates and hours logged
* Billable amounts
* SLA information
* CSAT scores
* Customer comments

The raw dataset was intentionally kept unchanged. Data cleaning and transformations were performed programmatically in the notebooks.
